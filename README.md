# 🎲 Monopoly Online

A modern, production-ready online multiplayer Monopoly game built from scratch.

---

## 🚀 Tech Stack

### Backend
- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- WebSockets

### Frontend
- React
- TypeScript
- Tailwind CSS

### DevOps
- Docker
- GitHub Actions (later)

---

## 📌 Project Goals

- Learn full-stack development
- Learn multiplayer architecture
- Build a reusable turn-based game engine
- Deploy a production-ready application
- Add AI-powered gameplay in future versions
